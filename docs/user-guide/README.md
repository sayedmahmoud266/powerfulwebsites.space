## Search and Discovery

### Basic Search

#### How to Search
1. **Locate the Search Bar**: Found in the hero section
2. **Enter Your Query**: Type any search term
3. **View Results**: Results update in real-time as you type

#### What You Can Search
- **Website Names**: "GitHub", "Figma", "Notion"
- **URLs**: "github.com", "figma.com"
- **Descriptions**: "AI tools", "design platform", "productivity"
- **Tags**: "Developer Tools", "AI Tools", "Productivity"

#### Search Tips
- **No quotes needed** for exact phrases
- **Case-insensitive** search
- **Partial matches** work (e.g., "design" finds "Figma")
- **Real-time results** - no need to press Enter

### Advanced Filtering

#### Tag-Based Filtering

Tags help you find websites by category:

**Available Categories**:
- AI Tools, Analytics, Backend, Collaboration
- Data Visualization, Database, Deployment
- Design Tools, Developer Tools, Note-taking
- Productivity, Project Management, Prototyping
- Authentication, Cloud Platform

#### Using Tag Filters
1. **Browse Tags**: View all available tags in the sidebar
2. **Select Tags**: Click to add tags to your filter
3. **Multiple Selection**: Select multiple tags (AND logic)
4. **Clear Filters**: Use "Clear All" to reset

#### Filter Logic
- **AND Logic**: Websites must have ALL selected tags
- **Persistent**: Filters remain active during search
- **Combinable**: Use search + tags together

### Combined Search and Filtering

#### Best Practices
1. **Start Broad**: Begin with a general search term
2. **Refine with Tags**: Add specific tags to narrow results
3. **Iterative Process**: Adjust search and tags as needed

#### Example Workflow
```
1. Search: "design"
2. Add Tag: "Design Tools"
3. Add Tag: "Collaboration"
4. Result: Collaborative design tools
```
